Test plan

  1. Run steps 2 to 5 in a Chrome tab first, then install the app (Chrome menu, then Add to home screen or Install app) and repeat them from the home-screen icon.
  2. In Score folder, tap Pick folder and choose a folder with PDFs. Open one, try one and two pages per screen, and draw on it with the stylus and with your palm resting on the screen.
  3. In Recent files, open two or three PDFs, including one from the Download folder. In Library, import a score or two.
  4. Close the app completely (swipe it away in recent apps), then reopen it. In Score folder, tap Reconnect and note whether you got a one-tap prompt, the full file picker, or nothing. Do the same with a file in Recent files.
  5. Turn on airplane mode and reopen the app. Check that it loads and that library scores open with their annotations.
  6. In Results, tap Copy report and paste it back to Claude, with what you saw in step 4.
